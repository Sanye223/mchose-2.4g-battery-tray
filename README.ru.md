Приложение для системного трея Windows, **не зависящее от фирменного ПО производителя**: оно постоянно отображает уровень заряда беспроводной мыши MCHOSE в области уведомлений панели задач, позволяет напрямую переключать ступени DPI и записывает каждое изменение заряда. Вся связь идёт через вендорский HID-канал официальной прошивки, поэтому MCHOSE M HUB устанавливать не нужно.

## ✨ Возможности

**Отображение заряда**
- Значок в трее — это и есть индикатор: силуэт мыши заполняется снизу вверх, автоматически инвертируется для светлой/тёмной панели задач и краснеет ниже порога. Есть ещё три стиля (батарея / число / кольцо)
- Левый клик открывает панель в стиле Win11 Fluent: карточка из матового стекла, скругления DWM, крупный процент заряда, полоса прогресса и значок зарядки
- Подсказка при наведении: имя устройства · заряд · текущий DPI · способ подключения · время обновления

**Переключение DPI**
- Шесть ступеней DPI в контекстном меню (по умолчанию 400 / 800 / 1600 / 3200 / 6400 / 26000), записываются в реальном времени во встроенную конфигурацию мыши
- Действуют одновременно на каналы USB и 2.4G; после каждой записи выполняется чтение с проверкой. Если таблица ступеней не совпадает, вы увидите явную ошибку, а не молчаливый «успех»
- Активная ступень определяется способом подключения: в проводном режиме читается USB-канал, в беспроводном — канал 2.4G

**История заряда**
- Одна запись на каждое изменение в 1 %, с точностью до секунды. При подключении кабеля опрос автоматически ускоряется до 10 секунд; при отключении возвращается исходный интервал
- Просмотр с группировкой по дням (с днями недели и статистикой), очистка одним кликом
- Тройная защита от «грязных» данных: фильтрация сбоев (скачки более 10 % не принимаются), база записи переносится из последнего сохранённого значения (перезапуски ничего не теряют), а единичные изменения больше 5 % в журнал не попадают

**Прочее**
- Порог низкого заряда (настраивается 10 %–40 %), автозапуск, интервал опроса от 30 секунд до 10 минут
- При сбое чтения сохраняется последнее значение, и значок не мигает серым; при подключении кабеля чтение автоматически переключается на проводной канал

## 📦 Получение

Скачайте готовый exe со страницы [Releases](https://github.com/Sanye223/mchose-2.4g-battery-tray/releases) и запустите двойным кликом (данные хранятся в профиле пользователя, реестр не затрагивается).

Либо соберите из исходников:

```bat
git clone https://github.com/Sanye223/mchose-2.4g-battery-tray.git
cd mchose-2.4g-battery-tray

:: Python 3.13+ (требуется tkinter)
python -m venv tkvenv
tkvenv\Scripts\python -m pip install pyinstaller hidapi pillow
tkvenv\Scripts\python -m PyInstaller --noconfirm --clean "2.4G电量托盘.spec"
```

> `fetch_wheels.py` — вспомогательный скрипт: офлайн загружает зависимости сборки, когда доступ к PyPI напрямую невозможен.

## 🚀 Использование

| Действие | Функция |
|---|---|
| **Левый клик** по значку | Показать / скрыть панель заряда |
| **Правый клик → DPI 档位** | Переключение ступени DPI (точка отмечает текущую) |
| **Правый клик → 电量记录…** | История изменений заряда с группировкой по дням |
| **Правый клик → 刷新间隔** | 30 с / 1 / 2 / 5 / 10 мин (при зарядке автоматически 10 с) |
| **Правый клик → 低电量阈值** | 10 %–40 %; ниже порога значок краснеет |
| **Правый клик → 图标样式** | Мышь / батарея / число / кольцо |
| **Правый клик → 开机自启** | Автозапуск (запись в ключ Run HKCU, только текущий пользователь) |

Флаги командной строки (для диагностики):

```bat
2.4G电量托盘.exe --cli          :: одно чтение заряда, вывод и выход
2.4G电量托盘.exe --panel        :: открыть панель сразу после запуска (если значок свёрнут)
2.4G电量托盘.exe --interval 10  :: временно переопределить интервал опроса
```

## 🖱 Адаптация ступеней DPI

Правый клик по значку → **DPI 档位**: шесть ступеней отображаются фактическими значениями (400–26000), точка отмечает текущую, один клик записывает её во встроенную конфигурацию мыши:

![Меню ступеней DPI](docs/dpi-menu.png)

Подсказка при наведении синхронно показывает действующий DPI. Ступень определяется способом подключения: в проводном режиме читается USB-канал, в беспроводном — 2.4G. Если чувствительности X / Y различаются, отображается как `800/400`:

![DPI в подсказке](docs/dpi-tooltip.png)

**Порядок переключения**: чтение встроенной конфигурации (с проверкой байта команды и фильтрацией нулевых эхо) → запись обратно в формате кадра A7 Pro → пауза 250 мс и чтение с проверкой «ступень применилась + таблица цела» → обновление меню и подсказки. Весь процесс занимает около секунды; при сбое любого шага запись попадает в журнал, а исходная конфигурация сохраняется — таблица никогда не повреждается молча.

> У A7 Pro формат кадра записи **не изоморфен** кадру чтения: отправка кадра чтения обратно повреждает всю таблицу. Это ключевое отличие от реализации FerrisPulse — подробности в [docs/PROTOCOL.md](docs/PROTOCOL.md).

## 🗂 Где хранятся данные

Все данные находятся в `%APPDATA%\MchoseBattery\`:

| Файл | Содержимое |
|---|---|
| `tray.json` | Настройки (интервал / порог / стиль / автозапуск) |
| `history.json` | История изменений заряда (до 800 записей, с ротацией) |
| `tray.log` | Журнал работы (детали сбоев чтения и результаты смены DPI — здесь) |

## 🔌 Заметки о протоколе и реверс-инжиниринге

Полные форматы кадров описаны в комментариях [`mchose_hid.py`](mchose_hid.py); подробный процесс реверса и подводные камни — в [`docs/PROTOCOL.md`](docs/PROTOCOL.md). Самые важные выводы:

- Полезная нагрузка запроса заряда — `0x06`; **`F4 55` — это команда перезагрузки профиля**: отправив её, вы заставите мышь перечитать встроенную конфигурацию, и DPI будет сброшен
- У A7 Pro **кадр записи DPI не изоморфен кадру чтения**: обратная отправка кадра чтения с изменёнными байтами ломает всю таблицу (в тестах X стал 26000/8193/16387)
- Канал 2.4G иногда присылает мусорные пакеты (наблюдалось: 83 % → 6 % → 83 %); и отображению, и истории необходима фильтрация скачков
- При подключении кабеля мышь переключается в проводной режим с другим PID, поэтому перечисление устройств должно принимать широкие условия

## ❓ FAQ

**В: Показывается «设备未响应» (устройство не отвечает)?**
В спящем режиме или при выключении прошивка не отвечает на опрос. Это нормально — пошевелите мышь, и всё восстановится. Если ответа нет долго, строка «found N interfaces» в журнале покажет, жив ли вообще канал.

**В: Нет показаний заряда во время зарядки?**
При подключении кабеля мышь переключается в проводной режим (другой PID); программа автоматически сканирует все интерфейсы-кандидаты. Если не помогло, создайте issue, приложив раздел «读取失败» из `tray.log`.

**В: Сменил DPI, но в игре ничего не изменилось?**
Проверьте в журнале запись «已切换到 XXX DPI». Некоторые игровые движки кэшируют настройки мыши — перезапуск игры решает проблему.

**В: Значок не появился в трее?**
Сначала проверьте в Диспетчере задач, что запущен `2.4G电量托盘.exe`. Windows по умолчанию прячет новые значки в области переполнения: нажмите стрелку «^» возле часов. Чтобы закрепить значок: Параметры → Персонализация → Панель задач → Другие значки панели задач → включите переключатель (Windows 10: Параметры панели задач → Выберите значки, отображаемые на панели задач).

## 🧪 Совместимость

| Устройство | Статус |
|---|---|
| MCHOSE A7 Pro (PAW3395, 2.4G + провод) | ✅ Полностью проверено (заряд / история / DPI / переключение при зарядке) |
| Другие MCHOSE серии A7 / A5 | То же семейство протоколов; в теории должны работать — отчёты приветствуются |

Пробуется любой интерфейс с VID, начинающимся с `5253` / `3837`, так что другие модели MCHOSE могут заработать сразу.
